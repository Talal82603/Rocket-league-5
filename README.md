# Rocket Arena 3D

A browser-based 3D car-soccer prototype designed for GitHub Pages.

## Upload
Put `index.html`, `style.css`, and `game.js` in the root of your repository. GitHub Pages can serve it directly.

## Controls
- Keyboard: WASD / arrows = drive + steer, Shift = boost, Space = jump, E = ball cam, Esc = pause.
- Controller: left stick drives/steers, A/Cross jumps, RT/R2 boosts.
- iPad/touch: virtual stick + BOOST/JUMP/AIR/BALL CAM buttons.

## Included
3D stadium, dynamic lighting, bloom, third-person car camera, ball cam, boost meter, small/large boost pads, boost recharge, jumping, ball physics, goals, scoreboard, 5-minute match clock, overtime state, AI teammates/opponents, garage colors, FOV setting, camera sensitivity setting UI, controller support and touch controls.

## Important
This is an original browser game inspired by arcade car-soccer mechanics, not a copy of Rocket League assets or code. It uses Three.js from jsDelivr at runtime, so the browser needs internet access when the page loads.

A true 1:1 Rocket League clone (networked multiplayer, production-grade vehicle physics, licensed assets, replay system, ranked matchmaking, full animation/audio pipeline, etc.) is far beyond what a single static GitHub Pages zip can realistically contain. This build is meant to be a much more complete 3D starting point than a 2D mockup.
